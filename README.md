# 🧮 Calculator App

A simple and responsive calculator web application built using HTML, CSS, and JavaScript.  
It performs basic arithmetic operations with a clean and user-friendly interface.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 🧹 Clear screen (C)
- ⌫ Delete last digit
- ⚡ Error handling (invalid input protection)

---

## 💻 How it works

- User clicks buttons to enter numbers and operators
- JavaScript updates display in real-time
- `eval()` is used to calculate the result
- Try/catch handles errors safely

---

## ⚙ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
